# 公众号统计型 DNA 规则

## 建模

- 每个判断先落到文章级证据，再判断是否跨篇稳定。
- 定性特征进入 DNA 的条件：出现在至少 60% 样本，且近期样本没有系统性反转。
- 单篇高频但跨篇不重复的表达只能进入例外区。
- 先描述作者真实习惯，不把通用写作偏好当作作者 DNA。

## 微信适配

- 中文正文以句号、问号、感叹号切句；长句、短句和一句成段都可以是签名。
- 微信排版元素不计入 DNA 指标，避免把模板、编辑器或历史视觉误判为作者表达。
- 不使用海外平台英文违禁词清单。工具只统计表达，不做合规判定。
- 营销、医疗、金融、法律等敏感表述只标记为风险观察，交由发布前合规流程处理。

## 交付

- instruction 必须是“写时怎么做”，不是风格评论。
- evaluation 必须有观测物、计算公式、容差和通过线。
- metrics 必须能被命令重新读取并计算，不依赖主观回忆。
