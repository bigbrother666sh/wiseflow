# 起号与账号诊断 Workflow

新号起号、老号诊断、定位梳理、内容支柱搭建走这个。

## 入口判断

用户说以下话时走：
- "我想做个公众号，从零开始"
- "帮我看看这个号还有没有救"
- "给我们号把个脉"
- "梳理一下内容方向"
- "搭建内容支柱"

## 先看手里有什么

### 情况 A：有账号名，且 `wx-mp-hunter` 的 posts-list 功能可用
**自己先抓数据，别上来就问用户。**

1. 调 `wx-mp-hunter posts-list --recent 30 --accounts <公众号名>` 抓最近 30 篇可获取文章
2. 抓不到/搜不到账号 → 告知用户未配置本地微信容器，posts-list 功能无法使用，请用户手动提供目标账号的代表文章链接。
3. 能抓到 → 自己先分析一波，能从数据里得到的就不问用户

基于抓到的内容，可以分析出：
- 内容支柱有哪些（在写哪些方向）
- 内容质量大概什么水平
- 内容大概是什么调性（样本充足时跑 style-profiler 拿统计 DNA）
- 选题模式、标题风格
- 发布频率、时间

**然后带着自己的分析再跟用户聊**，缺什么再补问什么。

### 情况 B：没有账号名 / hunter 用不了 / 新号还没内容
一次问清楚以下 8 件事：

| 字段 | 为什么要问 |
|------|-----------|
| 目标 | IP 信任 / 流量主 / 获客 / 销售 / 社群 / 专栏 |
| 赛道 | 大类、细分、最窄切入 |
| 读者 | 谁有痛点、有消费能力、有转发动机 |
| 变现 | 最终卖什么、验证什么、沉淀什么 |
| 证明 | 案例、资质、经验、素材、故事 |
| 产能 | 每周几篇、有没有人帮忙、冲刺周期 |
| 阶段 | 新号 / 沉寂号 / 不稳定 / 低阅读 / 活跃中 |
| 约束 | 合规边界、宣传限制、版权、品牌语气 |

不要拿着半个需求就开干，不然后面全是返工。

用户如果能提供一些样本文章/参考账号，一起给过来最好。

## 起号全流程（新号 / 重建定位）

### Step 1 — 模式判断
根据目标和资源，判断走哪条路：

| 模式 | 适用 | 优先优化 |
|------|------|---------|
| IP 信任号 | 做品牌、服务、产品、读者信任 | 清晰承诺、稳定赛道、专业度、留存、转化 |
| 流量主号 | 测试流量收益、低成本内容 | 细分主题、生产系统、原创度、版权安全 |
| 修复号 | 旧内容、低阅读、定位漂移 | 诊断、清理、垂直冲刺、信任重建 |
| 放大型号 | 已有部分有效选题 | 模式扩展、主题簇、系列化、转化 |

默认往 IP 信任号方向靠，除非用户明确说要做流量主。

### Step 2 — 账号地基
产出一套定位基础：

**定位句模板**：我帮助[目标读者]，用[方法/内容承诺]解决[具体痛点]，让他们获得[理想结果]。

转成具体 deliverable：
- 头像 / 名称 / 简介 / 自动回复 / 固定开场白
- 3-5 个内容支柱（分别承接搜索、信任、故事、证明、转化）
- 关键词宇宙（类目词、痛点词、场景词、人群词）

### Step 3 — 对标系统
找对标不是找大号。优先选：读者接近、近期有真实数据信号、中腰部、有可复用模式。
交付对标记录表（5-10 个账号、20-50 篇起步）。

### Step 4 — 选题库
按 7 类搭初始选题库：搜索、信任、故事、情绪、证明、转化、留存。
每类至少 5 个候选选题。

**如果有账号数据**，用真实数据反推什么选题在起作用，不是凭空编。

### Step 5 — 内容 DNA
- 有 3 篇以上样本 → 按 `style-dna.md` 统计 DNA
- 没样本 → 向用户确认后先用 `dna/wx_mp/default-business.md`，等有内容了再迭代
- 后续生产必须按 instruction 写作，并执行对应 evaluation
- 详情走 `style-dna.md`

### Step 6 — 首个 30 天日历
| 阶段 | 天数 | 干什么 |
|------|------|--------|
| 地基 | 1-3 | 定位句、主页五件套、内容支柱 |
| 对标 | 4-7 | 账号+文章对标、模式库 |
| 草稿储备 | 5-10 | 10-15 篇简报或草稿 |
| 首轮冲刺 | 8-20 | 稳定发布、保持垂直 |
| 模式扩展 | 21-27 | 复用有效模式、做系列 |
| 复盘 | 28-30 | 排名选题/标题/结构/行动引导，定下一轮重点 |

### Step 7 — 交付 + 确认
打包给用户，确认大方向。调整后定稿，作为后续内容生产的基准。

## 老号诊断

按失败环节倒推：

| 现象 | 可能原因 | 修法 |
|------|---------|------|
| 曝光低 | 信号不清、赛道漂移、合规风险、内容弱 | 收紧主页、保持垂直、查风险、更一致 |
| 有曝光打开低 | 标题弱、选题泛、读者不匹配 | 重写标题、强化钩子、更具体 |
| 打开完读低 | 开头慢、语言端着、没故事张力 | 朋友脑改写、加冲突加例子 |
| 阅读收藏低 | 不够实用、缺清单模板流程 | 加可带走资产、表格、步骤 |
| 阅读评论低 | 没明确问题、没身份张力 | 问一个跟读者处境有关的具体问题 |
| 互动关注低 | 有用但账号承诺不清 | 强化简介、系列承诺、开场白 |
| 关注转化弱 | 行动引导不清或太早销售 | 站内下一步、FAQ、诊断入口 |

**不给通用阈值下结论**——类别内相对基准比行业均值靠谱。
