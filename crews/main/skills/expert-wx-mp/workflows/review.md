# 数据复盘 Workflow

看数据、做复盘、分析对标、找改进方向走这个。

## 与 content-calibrator 的边界

- **本 workflow 回答「数据怎么了、为什么」**：按需的单篇诊断、周期性复盘、对标分析，产出诊断结论与行动项。
- **`content-calibrator` 回答「这个 DNA 好不好、该怎么改」**：按量触发的 DNA 表现评估（每平台每 DNA 累积 ≥5 条成熟记录），产出 `dna/wx_mp/<dna-id>/evals/` 评估报告与 DNA 更新建议。
- 分工规则：本 workflow **不生成评估报告、不直接改 DNA**；周期复盘读取 `evals/` 报告作素材，不重复计算。诊断或复盘发现风格规则层面的问题时，移交对应路径：DNA 评估/更新建议走 `content-calibrator`，采纳后走 `style-dna.md`。

## 入口判断

用户说以下话时走：
- "看看数据怎么样"
- "最近的文章复盘一下"
- "对标一下 XX 号"
- "为什么这篇阅读这么低"

单次诊断、周期性复盘、对标分析——都走这个，粒度不同而已。

## 单篇诊断

Step 1 — 拿数据
- 调 `wx-mp-engagement` 抓具体数据
- 没有就从 published-track 库里查

Step 2 — 按失败环节倒推
从曝光 → 打开 → 完读 → 收藏 → 评论 → 关注 → 转化，逐段找问题：

| 卡在哪 | 看什么 |
|--------|--------|
| 曝光低 | 标题关键词、赛道垂直度、账号信号 |
| 打开低 | 标题钩子、开头承诺、选题匹配度 |
| 完读低 | 开头节奏、语言密度、故事张力 |
| 收藏低 | 实用性、可带走资产 |
| 评论低 | 互动问题、身份张力 |
| 关注低 | 账号承诺、系列感 |
| 转化低 | CTA 时机、转化路径 |

注意：单篇绝对值要放在该账号自身水位里看（新号天然低、老号天然高），优先对比同账号近期作品，不拿跨账号绝对值下结论。

Step 3 — 给出 3 条具体改法
不说"加强内容质量"这种废话。每条必须说清楚改什么、怎么改、为什么。

Step 4 — 判断是否移交 DNA 路径
- 改法只涉及单篇执行（标题重写、时机调整、封面更换）→ 直接给建议，到此为止。
- 改法指向风格规则（"我们的开头节奏总是拖"、"标题套路不行"）→ 告知用户：这属于 DNA 层面问题，建议等 `content-calibrator` 的 DNA 表现评估（凑满 5 条成熟数据自动触发），或现在手动触发（`dna-eval.sh --force`）；采纳后走 `style-dna.md` 更新。不在本 workflow 里直接改 DNA。

## 周期性复盘（周 / 月）

Step 1 — 拉数据与既有评估
- 调 `wx-mp-engagement fetch-all` 批量更新近期数据
- 从 published-track 库里拉周期内所有文章
- 读取 `dna/wx_mp/<dna-id>/evals/` 下周期内的评估报告作素材——趋势、比值、归因结论直接引用，不重复计算

Step 2 — 排名分析
- Top 3 为什么好（选题 / 标题 / 结构 / 时机）
- Bottom 3 为什么差（拆开看哪段掉的）
- 共性规律：表现好的有没有共同模式
- 排名看同账号相对表现与趋势，不跨账号比绝对值

Step 3 — 对照趋势和目标
- 跟账号自身趋势比（近期 vs 此前，比值走向见 evals/ 报告）
- 跟用户设定的目标比
- 类别内相对基准 > 通用阈值

Step 4 — 产出行动项
- 下一轮重点做什么（最多 3 件事）
- 停掉什么（效果不好的类型/栏目）
- 加大什么（效果好的方向）
- 要测试的假设（1-2 个，下轮验证）
- 涉及风格规则变更的行动项，标注走 `content-calibrator` → `style-dna.md` 路径，不在复盘里直接改 DNA

**复盘必须有行动项**——没有行动项的复盘是自嗨。

## 对标分析

Step 1 — 选对标账号
不是越大越好。原则：读者接近、近期有数据信号、中腰部、有可复用模式。

Step 2 — 拆 20-50 篇
重点看：标题模式、结构类型、开头钩子、情绪触发、证明方式、行动引导。

**如果 `wx-mp-hunter` 的 posts-list 功能能用** → 直接抓对标账号的文章列表，省很多事。
**不能用** → 告知用户未配置本地微信容器，posts-list 功能无法使用，请用户手动提供目标账号的代表文章链接。

Step 3 — 提炼可复用 pattern
不是抄，是拆。把别人的结构转成自己能用的模式。
至少提炼出 3 个可以直接试的写法/结构/标题套路。

Step 4 — 给出落地建议
哪些下周就能试、哪些需要积累、哪些是别人的禀赋学不来。
对标 pattern 要进 DNA 时，走 `account-benchmark.md`（独立对标 DNA → 采纳后并入基线 DNA）。
